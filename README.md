 Ресторан «Морской вкус»
 
Автоматизированное рабочее место (АРМ) администратора и официанта для ресторана морепродуктов. Разработано в качестве дипломного проекта.

 Технологии
Язык: C#
Платформа: WPF (.NET 8)
База данных: Microsoft SQL Server (LocalDB)
ORM: Entity Framework Core

Инструкция по запуску
1. Скачайте проект на компьютер (кнопка Code -> Download ZIP).
2. Откройте файл `WpfApp1.slnx` в Visual Studio.
3. **Настройте базу данных:** Откройте файл `DatabaseScript.sql` (он находится внутри папки `WpfApp1`). Скопируйте весь код из него и выполните в SQL Server Management Studio (SSMS), чтобы создать таблицы.
4. Запустите приложение через Visual Studio (F5).
